Configuración inicial

1. Cambia la contraseña del admin por defecto. El usuario inicial es admin@makeseo.local con contraseña admin123. Créate una cuenta nueva con rol admin y elimina la default.

2. Google OAuth (opcional). Para activar login con Google, configura las variables de entorno GOOGLE_CLIENT_ID y GOOGLE_CLIENT_SECRET en Cloudflare Pages → Settings → Environment variables.

3. Crea clases y preguntas. Visita /academia/admin-classes.html (próximamente) o usa los endpoints /api/agent-classes directamente.
